# 御坂内核（astrbot_plugin_yuyu_kernel）

给一个角色装上一颗会变的心、一套会记得的记忆，和一个会等人的作息。

## 功能

- **情绪核心**：九维情绪 + 慢心跳，期待值与责怪压力，四个状态（平静 / 委屈 / 害怕 / 关闭）
- **记忆**：笔记 / 疤 / 习惯，SQLite 全文检索，可选本地向量检索
- **承诺回访**：答应的事到点提醒
- **群友档案 / 世界书 / 关系网**：语气禁忌、触发词事实卡、实体关系
- **风格审批**：学到的说话方式先待批，批准后才生效
- **自动审核**：回复前过滤敏感词
- **人格演化**：只统计句长与语气，不改人格文本
- **备份与周记**：整包 zip、按周导出
- **本机控制台**：浏览器打开 `http://127.0.0.1:6197/`（端口可配）

## 安装

1. 放进 `data/plugins/`，重启 AstrBot
2. 在插件配置里填：
   - `owner_id`：主人的 QQ 号
   - `owner_umo`：例如 `aiocqhttp:FriendMessage:123456`
   - `owner_name`：你对主人的称呼
   - `wake_names`：群里叫她就等于叫醒的名字，逗号分隔
3. 页面上会出现「御坂内核」，浏览器打开控制台地址即可

## 可选依赖

- `sentence-transformers`：启用本地向量检索（缺失时退回全文检索）
- `ffmpeg`：理解视频与动图
- 本机 TTS 服务：填了 `tts_proxy` 才会出现「听她的声音」

## 数据位置

```
data/plugin_data/astrbot_plugin_yuyu_kernel/
  notes/    笔记、疤、习惯
  extra/    情绪、承诺、档案、世界书、关系网、风格队列
  backups/  备份
  digests/  周记
```

## 说明

- 人格文本不在此插件内，插件只读不改。
- 面板数值建议只给主人看，不要发回给角色本人——她会开始「演数值」。
